# Lançar · Demandas do Ribeiro

Base de conhecimento da agência: o que aprendemos, como trabalhamos, o estado de cada demanda e as ferramentas que reaproveitamos. Repositório privado. **Nada de senha, chave ou token aqui.**

## Comece por aqui
| Arquivo | Para quê |
|---|---|
| [ESTADO-DEMANDAS.md](ESTADO-DEMANDAS.md) | Estado atual de cada cliente e demanda (ler antes de qualquer trabalho) |
| [COMO-TRABALHAMOS.md](COMO-TRABALHAMOS.md) | Gostos, regras de design e desempenho, tom com clientes, colaboração com os agentes |
| [conhecimento/](conhecimento/) | Robôs de WhatsApp, infra (plano VPS), preços, vídeo (método, componente iPhone 3D, projeto modelo), cardápio SaaS, landing pages |
| [clientes/](clientes/) | Estado, pesquisas e roteiros por cliente |
| [ferramentas/pagespeed/](ferramentas/pagespeed/) | Script que mede desempenho (meta 90+ no celular) |
| [memoria/](memoria/) | Cópia da memória do projeto no Claude (foto de 23/10/2026) |

## Regra de atualização
Toda demanda que muda de estado atualiza `ESTADO-DEMANDAS.md` e o `ESTADO.md` do cliente. Toda crítica do Ribeiro vira uma linha em `COMO-TRABALHAMOS.md` (crítica → regra).

## Onde ficam as outras coisas
- Arquivos de trabalho do dia a dia: pasta compartilhada do projeto no Claude (`/mnt/project-files/`).
- Código dos produtos: repositórios próprios (ver tabela em `ESTADO-DEMANDAS.md`).
- Painel "Clientes do Ribeiro" (clientes, cobranças, financeiro, tarefas): https://claude.ai/artifact/5Linm5nE8UiFeRqNtfs8pt
